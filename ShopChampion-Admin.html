Step 1 of 2 — Firebase Database
Your own free database — data stays with you forever
📋 How to get your Firebase config (2 min):
1. Go to console.firebase.google.com
2. Click Add project → name it anything → Continue
3. Click the </> Web icon → Register app → copy the config
4. Go to Build → Firestore Database → Create → test mode
5. Go to Build → Storage → Get started → test mode
