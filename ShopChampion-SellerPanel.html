📌 How to paste your Supabase credentials into the customer app:
Open ShopChampion-Admin.html in a text editor → find SC_SUPABASE_URL and SC_SUPABASE_ANON near the top of the <script> → replace with your Supabase URL and anon key → save → distribute that file to customers.
🔑 Service Role Key (used here in Seller Panel) → Supabase Dashboard → Project Settings → API → service_role. Keep it secret — never put it in the customer app file.
⚡ Disable a customer instantly by clicking the red button — their app locks within seconds on next load.
⚡ Re-enable when they pay — app unlocks immediately.
🔥 Firestore Rules for Shop Activity: Go to Firebase Console → Firestore → Rules and make sure the users collection is readable. Add this rule:
match /users/{phone}/{document=**} { allow read: if true; }
